# Projet JavaScript : Boucles et Fonctions

## Description
Ce projet a pour objectif de pratiquer les **fonctions** et **boucles** en JavaScript, dans un contexte proche du développement professionnel.  
Chaque fichier contient une fonction à compléter ou créer, testée automatiquement via des tests unitaires.  

L’exercice permet de renforcer la logique, la modularité et la réutilisabilité du code.
